# TP Modèles génératifs avec PyTorch (MNIST)

Classifieur, auto-encodeur et VAE entraînés sur MNIST.

## Lancer le projet

    uv sync
    # puis ouvrir Modeles_generatifs.ipynb dans VS Code
    # (kernel : .venv) et exécuter Run All

## Contenu

1. Chargement de MNIST
2. Modèle discriminatif (classifieur)
3. Auto-encodeur simple (espace latent 2D)
4. VAE : reconstruction, génération, exploration de l'espace latent
